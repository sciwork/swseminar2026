你是否曾想過：「**如果我能清楚描述想法，AI 是否就能做出產品？**」
讓我們將模糊想法轉換成清晰可執行的規格，使用 AI 開發出你預期的功能！

- 講者：JUGG，派森科技創辦人，具18年經驗之敏捷教練與產品顧問。
- 語言：中文
- 時間：3.5 小時

---

## 學習目標

- 定義問題背景，釐清真實痛點。
- 建立行動與價值關聯，形成策略脈絡。
- 找出需求動機與角色，轉為可行故事。
- 將模糊需求轉為具體可驗證的條件。
- 生成準確且具上下文的規格文件。
- 以 AI IDE 視覺化需求，驗證可行性。

---

## 課程內容

- 使用 AI 工具定義產品目標和規格
  - Impact Mapping：透過目標、價值與角色的連結，建立可實驗的產品策略方向。
  - User Story：探索使用者角色與需求背後的動機，將問題轉化為以使用者價值為中心的可執行故事。
  - Acceptance Criteria：給定明確條件和需求範圍，使工作能依據規格地正確執行。

- 實際體驗「痛點分析 → 需求釐清 → PRD 撰寫 → Prototype 生成」的完整需求制定流程。

---

## 事前準備

- 筆記型電腦
- GenAI 工具：Gemini / ChatGPT / Claude / Grow 任一
- AI IDE：Cursor / Claude Code 任一

你是否能想像：「**只靠一台電腦就能搭建網路環境？**」
透過 GNS3，你不需昂貴設備或佈線，只要拖拉元件即可建立模型，快速理解網路的真實運作。

- 講者：Steve Chan，網路軟體開發者。
- 語言：中文
- 時間：3 小時

---

## 學習目標

- 了解 GNS3 的運作方式與基本使用情境。
- 建立基本網路拓樸並理解節點間的連線關係。
- 利用封包擷取工具觀察真實封包流動。
- 設計跨網段的虛擬網路架構並驗證其運作。
- 將模擬環境與真實網路串接，應用於開發、測試與 Demo。

---

## 課程內容

- 環境安裝：介紹 GNS3 的運作方式與常用元件，並完成安裝與基本設定。
- 網路基礎：理解基礎通訊行為，認識 ARP、IP 配置與基本轉送流程。
- 拓樸設計：建立單一網段拓樸並完成 IP 配置，熟悉拖曳節點、連線、調整參數的操作流程。
- 封包觀察：分析封包如何流動，熟悉如何利用封包觀察驗證拓樸是否符合預期。
- 進階連接：示範 GNS3 與實體網路的整合方式，探討可應用於測試、開發與 Demo 的進階情境。

---

## 事前準備

- 筆記型電腦：Windows 和 macOS 皆可。
- GNS3：確認 Docker 或 VM 支援，macOS 建議事先確認是否能不透過 VM 使用 local server。
